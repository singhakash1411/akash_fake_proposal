# Akash Fake Proposal 💌

A fun and simple single-page web project that playfully asks:  
**"Do you like me?"** with two buttons — **Yes** and **No** — both leading to the same cheeky response: **"I knew it!"**.

## Demo
[Live Demo](https://singhakash1411.github.io/akash_fake_proposal/)

## How to Use
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Click either button and enjoy the surprise.

## Features
- Single HTML file, no dependencies.
- Works offline.
- Lighthearted and playful interaction.
